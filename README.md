# Interface de Cadastro de Cliente - Banco Digital

Protótipo de uma tela de onboarding (abertura de conta) responsiva e limpa, simulando o fluxo inicial de um usuário ao se cadastrar em um banco digital.

# Tecnologia Utilizada
HTML5 (Estruturação semântica)
CSS (Estilização moderna e layout flexível)

# Objetivo Acadêmico
Colocar em prática conceitos de Front-end, focado em Experiência do Usuário (UX) e design de interfaces para sistemas web.
